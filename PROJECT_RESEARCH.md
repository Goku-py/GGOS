# NEXTRIX — Project Research

**Status:** Phase 1 deliverable · generated 2026-11-23 · all six research streams (`research/sources/r1–r6`) read in full by the coordinator and reconciled via `docs/RESEARCH_RECONCILIATION.md`.

**Global evidence verdict:** across all 14 reference projects plus the AME Wizard platform, **zero independently verified (VERIFIED) performance results exist**. Every performance number found anywhere (Hone's +51 %/+27.7 % Valorant, ReviOS's TSX "4–5×", FSOS-X's RAM/process/footprint figures) is a developer-reported DEV-BENCHMARK or DOCUMENTED claim. **None may be cited in NEXTRIX as evidence of performance.** Functional verification ≠ performance verification, per the directive.

## Per-project key findings

**FSOS-X** `[r1]` — closed-source; every finding DOCUMENTED/DEV-BENCHMARK. Valuable as a requirements source for NX18: verified-step session restore (R11), anti-cheat blocking reports, launcher-chain waits (10 min), capture-process exclusions (OBS/ShadowPlay/Medal), Gaming/Standard plan pair, "Recent Changes" audit trail, BitLocker detection stopping installs, iGPU-aware GPU-priority hiding. Cautionary: mitigation-off marketing contradicted by its own FAQ (Valorant/FACEIT users must keep mitigations); MPO toggle pulled twice; "no known issues" vs a long fixed-issue history; 40-hour-fresh-install contract is the opposite of NEXTRIX's apply-to-existing-systems mandate.

**XOS Playbook** `[r1]` — the strongest rollback machinery in the AME-playbook class: `StockValueCapture.ps1` (capture-refusal when already tweaked; `CaptureStatus`/`RestoredToStock` markers), per-area backups (DMA/MSI/HyperV), event-channel wipe gated on capture completeness, verified 3-fallback task disabling with exit codes, never-delete-active-plan rule, Wi-Fi exclusion via `*PhysicalMediaType`, guest-VM guard, TargetReleaseVersion pinning. Rejects: system-wide mitigation nuking with 0x22 masks, IFEO hijacks, VSS disable + log clearing, WU-off default, Unrestricted execution policy, UCPD fighting.

**XOS Toolkit** `[r1]` — the NX19 goldmine (reference-only, CC BY-NC-ND): full topology derivation from `GetLogicalProcessorInformationEx` (SMT flag, EfficiencyClass P/E/LP-E tiers, cross-group indexing), dies→CCD via `RelationProcessorDie`, **X3D detection by >2× per-die L3 cache asymmetry** (no name lists), LP→CPU-Set-ID mapping via `GetSystemCpuSetInformation`, CPU-Sets-default/affinity-fallback (single-group ≤64), per-process rule JSON with validation limits and quarantine-on-corrupt, BELOW_NORMAL 1.5 s enforcement service, pure-function parsers with synthetic tests. Cautions: `NtQuerySystemInformation` raw parsing (fragile, anti-cheat-sensitive); stable C# build unauditable; VM-only beta testing bar.

**AtlasOS** `[r2]` — the process benchmark for the whole field: services near-untouchable with Microsoft-doc citations; "VM gate" requiring disposable-VM evidence per build/arch before any startup change; validated first-backup-kept service export; resumable transactional installer with distinct exit codes; post-install re-read with `notApplied` honesty; power policy limited to four AC values with an explicit "what we don't change and why" exact-rollback table; CPU-vendor-aware mitigation values with a Vanguard CFG exception; hash-pinned CABs. Still rejects: Defender/SmartScreen/WebThreatDefense CBS removal + MoTW off regardless of choice; auto-updates off by default; UAC secure-desktop off; `custom:16000069` undocumented BCD. Same-week migration off AME Wizard is the ecosystem signal recorded in ADR-006 context.

**ReviOS** `[r2]` — the negative-results ledger: `revert.yml` documents 9+ tweaks that broke real software (svchost-split→XboxGipSvc; bam→Task Manager; mitigations→THE FINALS; disabledynamictick→ROG Ally sleep; BBR2→websockets; background-apps→GameBar; consumer-features→Your Phone; MouseHoverTime; VulnerableDriverBlocklist→FINALS). Rejects: Defender force-disabled during every deployment; unconditional VBS (silent no-op on Secured-core, #222); unconditional BitLocker-encryption prevention; chkdsk auto-check off; TSX enable (DEV-BENCHMARK + TAA re-exposure); hosts-file blocklists incl. Brave/VS endpoints; updates paused to 2038 by default; UCPD disable; IFEO taskkill hijacks; modsfire distribution (SHA256 at least published).

**SapphireOS / -Playbook** `[r3]` — most aggressive reference: ~250 services disabled (incl. Tcpip6/VSS/Themes/Spooler/LanmanServer), HPET + System Timer + Intel ME/AMD PSP device disables, microcode DLL renaming, `nx AlwaysOff`, WU frozen to 2050, self-deleting scripts, permanent root-certificate install (NoDefender cab), GPL-3.0 declared over proprietary bundles without notices. Genuinely useful: service Start-export-before-change; anti-cheat-aware DEP trio (FACEIT needs DEP on; Valorant `optin`); SSD/HDD opposite reg pairs; version-adaptive mitigation-mask derivation (technique transferable to journal capture); resync.bat temporary-enable micro-pattern; VMware guard.

**Vain** `[r3]` — right contract, closed implementation: session-scoped self-reverting scheduling ("all of it undone when the game closes"), per-process rule schema (Game=1/Background=3), thread-description matching, exist-checked NIC writes, per-action `builds:['>=26100']`, `nx optin` stance, honest beta labeling ("can help a lot or cost FPS"). Rejects: closed self-signed engine with RE prohibition (topology/sets-vs-affinity unverifiable), hardcoded 36-game table, hardcoded 45-byte mitigation mask, Defender file deletion (vendor-confirmed irreversible), `vssadmin delete shadows /all`, all-stock-plans deletion, unpinned silent updater, firewall block rules for explorer.exe.

**SynergyOS** `[r4]` — **unlicensed** (zero reuse); permanent Defender teardown + the same permanent-root-cert pattern; BCD timer forcing with no backup; updates paused to 2038 + driver delivery blocked; blanket Enum power zeroing; `BcastDVRUserService_389fd` hardcoded suffix fragility; no systematic build layer. Useful ideas (facts only): `Ndi\Params` capability probing before every NIC keyword write with min/max clamping; virtual-adapter exclusion lists; UCPD policy-fallback precedent (`AllowNewsAndInterests` when `TaskbarDa` is protected); option labels naming reversibility.

**SynToolkit** `[r4]` — the detection-quality benchmark: uncertainty-state pattern (missing ≠ Off; wrong type = `UnsupportedValue`; restore-point `Unverified` ≠ `Failed` with throttle awareness and always-close semantics), VRAM wraparound fix (`qwMemorySize` over WMI `AdapterRAM`, per-subkey try/catch), junk-SMBIOS sanitization, DDR map with explicit null → CPU-Z fallback, progressive disclosure for slow probes, GPU-vendor gating rationale, BCD via the WMI provider with read-after-write verification, pure testable detection functions, "Specs layer never modifies the system." Cautions: bundled `inpoutx64` kernel driver (hard caution); README/code floor mismatch.

**UltraOS** `[r4]` — the rollback-architecture benchmark and the closest philosophical ancestor of NEXTRIX: L0 restore point (throttle-aware, never deletes shadows) → L1 full pre-change snapshots (services/AppX/tasks) → L2 Start-only service undo with baseline diffing ("never blind-import ImagePath/Security blobs") → L3 never-executed stock inventory → L4 toggle pairs + per-change install report; validator-enforced never-touch service list; per-action provenance comments and honest-uncertainty annotations ("⚠️ UNVERIFIED existence on 26H2"); placebo rejection list; dry-run harness porting the engine's actual load rules; Defender never touched, updates never disabled, UCPD never fought, zero bundled binaries (166 KB playbook). One doc-vs-undo over-claim recorded as the integrity lesson.

**WinUtil** `[r5]` — the data-driven undo model: every registry/service change carries `OriginalValue`/`OriginalType` with a `<RemoveEntry>` sentinel; undo is a mechanical field-flip; conditional service undo protects foreign changes; idempotent executors; config import pre-validated before replacing state; DNS change with latency benchmark and abort-on-failure; restore point special-cased to run first; WaaSMedicSvc launch-protected-service workaround (direct registry `Start` write; SYSTEM deny-ACE clearing). Rejects: WU disable flow, `DISM /ResetBase` (irreversible), Edge dummy-exe hack, hosts-list appends, BitLocker-disable as an "Essential" tweak, no build guard.

**Sophia Script** `[r5]` — the guard-chain model: file-integrity checks, FullLanguage requirement, component-stability probes (Defender/WMI/SysMain/pagefile), architecture gate, **harmful-tweaker fingerprinting** (refuses systems tainted by 12 known optimizers), pending-reboot refusal, preset confirmation; edition-aware telemetry floor (Home/Pro get 1, Enterprise gets 0 — honest); policy hygiene (real setting keys, Registry.pol for gpedit visibility); DNS-over-HTTPS with resolve-probe verify-and-auto-rollback; paired-parameter undo always displayed next to the applied call; component cleanup without `/ResetBase`. Cautions: pinned-latest-UBR strictness bricks the script as Microsoft ships new patches; refusal path mutates the system (sets update-service values before exiting) — NEXTRIX refusals stay read-only.

**Hone** `[r6]` — commercial, closed, citation-only. Best-in-class *methodology claims*: 7-gate tweak admission (problem → mechanism → risk → metric-matched goal → 6–10 controlled runs → risk/benefit → scope) and metric discipline (1 %/0.1 % lows, frame times); session Game Mode with ~5 s watchdog, exclusion lists and a session report. All numbers are single-PC DEV-BENCHMARK; Epic-listing +51 % exceeds the vendor's own controlled +23.9–27.7 %; "fully revertible" contradicts the main site's narrower wording; ToS forbids content/screenshots without written permission (NEXTRIX cites URLs only); critical community reports (AV flags, bricked-drive thread) are unverified but recorded.

**AME Wizard platform** `[r6]` — see ADR-006: no standardized uninstall (Privacy+ removal = ISO in-place upgrade; universal reversibility is pre-1.0 future work); unsigned beta with Defender-exclusion instructions; `.apbx` fixed-password encryption documented as AV-evasion; `UseKernelDriver` option; verification discretionary via Discord/Telegram, lost on modification; engine (`trusted-uninstaller-cli`) MIT, GUI unpublished, official playbooks unlicensed. The 14-action declarative schema with per-action `builds`/`cpuArch`/`errorAction`, requirement gates and feature pages is the transferable asset NEXTRIX generates against.

## Research limitations (global)

1. Nothing was executed, benchmarked or installed anywhere; all findings are static source/page analysis. No VERIFIED tags exist anywhere by design of this phase.
2. Closed or partially unauditable: FSOS-X, Hone (closed); Vain's Governor (closed, RE-prohibited); SapphireOS ISOs (Discord-gated); XOS stable C# toolkit; wizard GUI; all bundled binaries (`.cab`, `.pow`, `.nip`, drivers, installers) — inferred from context only.
3. Web-search quota failures in R1/R6 limited COMMUNITY-CLAIM coverage; Reddit/YouTube/Discord content is snippet-level at best. GitHub API rate limits were worked around (HTML pages, authenticated MCP).
4. Large files not fetched are enumerated per stream (`r1–r6` "Research limitations" sections); findings never extend beyond files actually read.
5. Access date for everything: 2026-11-23. Repos move; release states are snapshots.
